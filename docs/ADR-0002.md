# ADR-0002: Local workspaces with durable evidence

**Date:** November 2, 2026. **Status:** Implemented for local development; NOT production-approved.

## Decision

Use the Node 22 built-in SQLite API as a dedicated, easy-to-run local persistence layer. The connected Supabase projects belong to other applications; neither is reused for Priorly. Tables: users, sessions, projects, research_runs, evidence. Passwords use salted scrypt hashes. Session tokens are random and SHA-256 hashed in storage; cookies use HttpOnly, SameSite=Strict, and Secure in production mode. SQLite foreign-key cascades and parameterized queries protect relational integrity. Every authenticated project read or mutation checks the owner ID on the server. Tests exercise cross-user reads, writes, research, and evidence review.

Evidence is separate from human interpretation. Retrieval stores source, URL, title, retrievedAt and the original run. Human labels are limited to: unreviewed, overlap, differentiated, needs-review, irrelevant. Rerunning a search cannot erase a previous review.

## Privacy and security limitations

This build binds to localhost by default. Do **not** deploy it on the public internet or use it for confidential IP. It lacks email verification, password reset, MFA, managed identity, encrypted-at-rest database storage, hardened distributed sessions/rate limits, disaster recovery, independent pen testing, and secure confidential file handling. Node 22 built-in SQLite is experimental. An authenticated cookie is not by itself a full production security design. The original public idea preview may store drafts in browser localStorage.

## Production gate

Before real customer data: provision a dedicated Priorly Postgres/Auth project, encrypt records and files, implement account verification and reset, MFA, cross-tenant RLS, audit/history, private bucket permissions, retention/deletion flows, managed backups, distributed rate limits and regression/security checks. Never reuse BlueCore or Prysm Style infrastructure. Patentability, ownership and freedom-to-operate conclusions require counsel review.
